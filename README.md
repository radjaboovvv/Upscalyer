# Upscalyer v1.0.0 (Beta Release)

> Professional AI Video Interpolation Tool for Editors & Creators

---

## English

> **AI-powered video frame interpolation software built for video editors and creators.**

### Key Features
* **Up to 240 FPS Interpolation:** Smooth out edits, gaming clips, and anime effortlessly.
* **Local Hardware Acceleration:** Powered by RIFE (ncnn-vulkan) and FFmpeg.
* **Sleek UI:** Dark Fusion theme with multi-language support.

### Important Limitations
* **Maximum File Size:** 400 MB.
* **Maximum Frame Rate:** Input video FPS must be below 240 FPS.

### Quick Start
1. Download and extract **`Upscalyer.zip`** to any folder.
2. Run **`install_ffmpeg.bat`** (installs FFmpeg automatically via winget).
3. Launch **`Upscalyer.exe`** and start rendering.

## Русский

> **Профессиональный инструмент для видеомонтажеров и эдиторов на базе ИИ.**

### Ключевые особенности
* **Интерполяция до 240 FPS:** Плавные переходы для эдитов, игровых моментов и динамичных роликов.
* **Локальное ускорение:** Работает локально через RIFE (ncnn-vulkan) и FFmpeg.
* **Удобный интерфейс:** Темная тема (Dark Fusion) и поддержка нескольких языков.

### Важные ограничения
* **Максимальный размер файла:** до 400 МБ.
* **Максимальная частота кадров:** исходное видео должно быть ниже 240 FPS.

### Быстрый старт
1. Скачайте и распакуйте архив **`Upscalyer.zip`** в отдельную папку.
2. Запустите **`install_ffmpeg.bat`** для автоматической установки FFmpeg через winget.
3. Запустите **`Upscalyer.exe`** и начните работу.
